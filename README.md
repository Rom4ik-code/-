# HydraMan — файлы сайта

В этом архиве:
- `index.html` — сам сайт (главная страница)
- `photos/` — папка с фотографиями, которые использует сайт

## Как загрузить на GitHub

1. Зайдите на github.com и создайте новый репозиторий (кнопка **New**), например с именем `hydraman-site`. Сделайте его **Public** — иначе бесплатный GitHub Pages не будет работать.
2. Откройте созданный репозиторий и нажмите **Add file → Upload files**.
3. Перетащите туда файл `index.html` и всю папку `photos` (с файлами внутри) — важно сохранить именно такую структуру: файл `index.html` должен лежать в корне репозитория, а фотографии — в подпапке `photos`.
4. Нажмите **Commit changes**, чтобы сохранить загруженные файлы.

## Как включить бесплатный хостинг (GitHub Pages)

1. В репозитории откройте **Settings → Pages** (в левом меню).
2. В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
3. В разделе **Branch** выберите `main` (или `master`) и папку `/ (root)`, нажмите **Save**.
4. Подождите 1–2 минуты и обновите страницу — сверху появится зелёная плашка со ссылкой вида:
   `https://ваш-логин.github.io/hydraman-site/`

Это и будет постоянная ссылка на сайт — её можно присылать кому угодно, она не зависит от Claude.
