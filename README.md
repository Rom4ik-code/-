# HydraMan — файлы сайта

Содержимое: `index.html` (сайт), папка `photos/` (фото: вода, отопление, сантехника, ремонт, котёл, пожарная система, тепловые насосы), файлы иконки (favicon.ico, favicon-16x16.png, favicon-32x32.png, apple-touch-icon.png, android-chrome-192x192.png).

## Загрузка на GitHub
1. Откройте репозиторий → **Add file → Upload files**.
2. Перетащите ВСЕ файлы и папку `photos` (index.html и иконки — в корень репозитория, фото — внутри `photos/`). Если в репозитории уже лежит старый index.html — загрузка с тем же именем заменит его.
3. Нажмите **Commit changes**.

## Включение GitHub Pages
Settings → Pages → Deploy from a branch → ветка `main`, папка `/ (root)` → Save. Через 1–2 минуты сайт откроется по ссылке вида `https://ваш-логин.github.io/название-репозитория/`.

## Если после загрузки видна старая версия
Откройте сайт в режиме инкогнито или нажмите Ctrl+F5 (на телефоне — откройте в другом браузере). Кэш браузера, особенно для иконки, может держаться долго. Также убедитесь, что на GitHub в файле index.html нет слова «демо» — значит, загрузилась новая версия.
